# CRS (Custom Registration System) Project

A Java-based registration system that handles loans, clients, and various data structures such as LinkedLists, Stacks, and HashSets. The project showcases object-oriented programming and the implementation of custom data structures to simulate real-world scenarios.

## Project Structure

The project is composed of several Java classes and interfaces:

- `CRS.java`
- `LinkedList.java`
- `Client.java`
- `Loan.java`
- `Person.java`
- `HashSet.java`
- `ListInterface.java`
- `StackInterface.java`
- `Stack.java`

---

## Features

- **Custom Data Structures**: Implementation of LinkedList, Stack, and HashSet to manage data efficiently.
- **Client and Loan Management**: Classes to represent clients and their respective loans.
- **Interfaces**: List and Stack interfaces to enforce consistent structure across implementations.
- **Person Class**: Base class for clients and other user-related functionality.
- **Comprehensive Exception Handling**: Ensures robustness in data operations.
